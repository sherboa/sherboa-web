under the hood

the project
sherboa engine is a free, independent project created for educational and experimental purposes.
it is designed as a simple tool for comparing video quality using VMAF, with a focus on video engineering, streaming and media systems.

powered by linux & all his friends
HTML · CSS · javascript · python · fastAPI · ffmpeg · docker · github actions · kubernetes · public cloud · terraform

netflix's VMAF
VMAF is an open-source perceptual video quality assessment algorithm developed by netflix.
however, please note sherboa engine is not affiliated with or endorsed by netflix.

ffmpeg
ffmpeg is a free and open-source multimedia framework for video processing and media analysis.
